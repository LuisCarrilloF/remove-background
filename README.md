# remove-background
App de escritorio con Flet t python que permite remover el fondo de una imagen, estoy cansado de usar Word y que no se remueva como yo quiero, como buen desarrollador decidi crear mi propia herramienta.

# Entorno de desarrollo
## Entorno Virtual
Primero se debe crear  el entorno virtual
```
python -m venv venv
```
despues debes activarlo. pude ser con las teclas `ctr` + `shift` + `p` y seleccionas la opcion de entorno virtual y despues la recomendada.

También puedes activarlo desde owerShell con:
```
.\venv\Scripts\Activate.ps1
```
